## About This Repo

This repository hosts static web projects — each self-contained in its own folder or as a standalone `index.html`. All sites are deployed automatically via **GitHub Pages**.

Each project is built with:
- Pure **HTML5**, **CSS3**, and **vanilla JavaScript**
- No npm, no build step, no dependencies
- Mobile-responsive and fast-loading by default

## Deployment

All projects are hosted on **GitHub Pages** for free.

To enable:
1. Go to **Settings** → **Pages**
2. Set source to `main` branch → `/ (root)`
3. Your sites go live at `https://kelvin-thegreat.github.io/website/`
